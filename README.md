# MovieVault - Movie Review Platform

A modern movie review and rating platform built with React, TypeScript, and Supabase.

---

## 🎯 PRIORITY: Content for AdSense Approval

### Main Focus: Blog Articles

**Location:** `src/pages/Blog.tsx` (line 35+)

**What You Need:**
- Write 10-15 **original blog articles** (500-800 words each)
- Topics: Film analysis, top 10 lists, genre guides, director spotlights
- See `src/data/blog-article-template.md` for writing guide

**Why This Matters:**
- Blog content = original value for AdSense
- Easier to make unique than per-movie reviews
- Shows expertise and editorial voice
- Main requirement for "low value content" fix

### Step 1: Open Blog File
```

```

### Example Article Entry:

## 🎬 Tech Stack

- **Frontend:** React 18, TypeScript
- **Styling:** Tailwind CSS, shadcn/ui
- **Backend:** Supabase
- **API:** TMDB (The Movie Database)
- **Routing:** React Router
- **Build:** Vite
